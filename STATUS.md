## 🎮 How It Works

1. **Start**: Run `python main.py`
2. **Menu**: Click START
3. **Your Turn**: Click on a stat you think will win
4. **Compare**: Computer's card reveals, winner is shown
5. **Result**: Winner takes both cards
6. **Continue**: Play until someone has all 39 cards
7. **Game Over**: Click PLAY AGAIN or close window

## 🔧 Customization

### Want to change stats?

2. Find the character
3. Change any stat (keep 1-100 range)
4. Save and play!
